🏦 Banco Python - Sistema Bancário Digital com Tkinter
Um aplicativo desktop de simulação bancária desenvolvido em Python, utilizando a biblioteca gráfica Tkinter, a biblioteca de manipulação de imagens Pillow e a biblioteca Faker para geração de dados fictícios em português (pt_BR).

🚀 Funcionalidades
Sistema de Autenticação:

Tela de login integrada com validação de número de conta e senha.

Tela de cadastro de novos perfis com preenchimento automático opcional gerado pelo Faker.

Painel do Cliente (BancoApp):

Exibição do saldo atualizado em tempo real formatado no padrão monetário brasileiro (R$).

Operação de Depósito com validação de entrada de dados.

Operação de Saque com verificação de saldo insuficiente.

Visualização de Dados Cadastrais (E-mail, Telefone e Endereço gerados via Faker).

Opção de logout para trocar de conta ou retornar à tela de login.

🛠️ Tecnologias Utilizadas
Python 3.x

Tkinter (Interface gráfica nativa do Python)

Pillow (PIL) (Processamento e manipulação de imagens)

Faker (Geração de dados falsos/realistas para testes)
